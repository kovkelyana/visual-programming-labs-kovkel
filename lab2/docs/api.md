# API Documentation — Lab 2 (Node-RED)

Базовый URL: **`http://localhost:1880`**

---

## 1. GET /api/text

Возвращает простой текстовый ответ.

**Параметры:** нет.

**Пример запроса:**
```
GET http://localhost:1880/api/text
```

**Успешный ответ (200):**
```
Привет! Это простой текстовый ответ.
```

---

## 2. GET /api/info

Возвращает JSON-объект с информацией.

**Параметры:** нет.

**Пример запроса:**
```
GET http://localhost:1880/api/info
```

**Успешный ответ (200):**
```json
{
    "name": "Ковкель",
    "role": "student",
    "lab": "lab2"
}
```

---

## 3. GET /api/items

Возвращает «товар» по его `id`. Использует **query-параметр** `id`.

**Параметры:**
- `id` (обязательный) — целое число от 1 до 5.

### 3.1. Успешный запрос

**Запрос:**
```
GET http://localhost:1880/api/items?id=3
```

**Ответ (200):**
```json
{
    "status": "ok",
    "item": {
        "id": 3,
        "name": "Товар №3",
        "price": 300
    }
}
```

### 3.2. Ошибка 400 — параметр отсутствует

**Запрос:**
```
GET http://localhost:1880/api/items
```

**Ответ (400):**
```json
{
    "status": "error",
    "code": 400,
    "message": "Параметр 'id' обязателен. Пример: /api/items?id=3"
}
```

### 3.3. Ошибка 400 — параметр не число

**Запрос:**
```
GET http://localhost:1880/api/items?id=abc
```

**Ответ (400):**
```json
{
    "status": "error",
    "code": 400,
    "message": "Параметр 'id' должен быть числом"
}
```

### 3.4. Ошибка 404 — товар не найден

**Запрос:**
```
GET http://localhost:1880/api/items?id=99
```

**Ответ (404):**
```json
{
    "status": "error",
    "code": 404,
    "message": "Товар с id=99 не найден. Доступны id от 1 до 5"
}
```

# Отчёт по лабораторной работе №3 — Bubble

## 1. Краткое описание выполненного

В рамках лабораторной работы №3 я освоила no-code платформу **Bubble**. Создано приложение **«Киноархив»** — сервис для ведения личной фильмотеки, рецензий и списков фильмов.

## 2. Промпт для AI-генератора (Часть 1)

Промпт, отправленный в AI-агент Bubble:

```
Создай приложение на тему «Киноархив — база фильмов и рецензий».
Пусть этот сайт требует регистрацию — у каждого пользователя личный кабинет.
Страницу обязательно создай по структуре header + body + footer.
Обязательно укажи в заготовке следующую строку: «ТВП: Ковкель».

Функционал приложения:
1. Пользователь регистрируется и входит в личный кабинет.
2. На главной странице отображается подборка фильмов (тренды/популярное) 
   и последние рецензии пользователей.
3. Страница «Фильмы» — список фильмов с поиском и фильтром по жанру.
   Каждый фильм имеет карточку: название, год, режиссёр, жанры, теги, 
   описание, актёрский состав, средний рейтинг.
4. На странице фильма можно оставить рецензию с оценкой (1-10), 
   посмотреть все рецензии других пользователей.
5. Пользователь может добавлять фильмы в свои списки: 
   «Посмотреть позже», «Просмотренные», «Любимые».
6. Полный CRUD для фильмов: создание, чтение, редактирование, удаление.
7. Интерактивные элементы: поиск, фильтры, формы, кнопки.
```

## 4. Использованные AI-промпты

### 4.1. Промпт для CRUD-страницы

```
Создай новую страницу «movies-crud» для полного CRUD-управления фильмами 
(Data Type «Фильм»). 

На странице должны быть:
1. Форма добавления нового фильма с полями: Название (input), 
   Год (input), Режиссёр (input), Описание (multiline input), 
   Средний рейтинг (input), Постер (image uploader).
   Кнопка «Добавить фильм».
2. Список всех фильмов в виде карточек или таблицы, где для каждого фильма 
   есть кнопки «Редактировать» и «Удалить».
3. При нажатии «Добавить фильм» — workflow создаёт новую запись типа Фильм.
4. При нажатии «Удалить» — workflow удаляет запись.
5. При нажатии «Редактировать» — открывается popup или форма редактирования.
```

## 5. Освоенные элементы и workflows

### Data Types
- **`Фильм`** — 11 полей: Название, Год, Режиссёр, Описание, Жанры, Теги, Постер, Средний рейтинг, Число рецензий, Актёрский состав, Название для поиска
- **`Список`** — Заголовок, Тип, Фильмы (list of Фильм)
- **`Рецензия`**
- **`User`** — Name, Любимые, Посмотреть позже, Просмотренные, Роль

### Workflows (CRUD)
- **Create** — `Добавить фильм` (создаёт новую запись `Фильм`)
- **Read** — Repeating Group на странице `movies-crud` (показывает список)
- **Update** — `Edit open edit` + `Edit save` (изменение существующего фильма)
- **Delete** — `Delete ask` + `Delete confirm` (удаление с подтверждением)

### UI
- **Global variable** `brand-accent` (цвет) — применена к кнопке
- **Style** — новый стиль кнопки с использованием переменной
- **Component** из Drag & drop UI Components — добавлен на страницу
- **Header + Body + Footer** — структура страниц

### Ачивка (Plugins)
- **Slideshow A** — плагин слайд-шоу (не из лекции)

## 7. Выводы

Открыла для себя новый инструмент.С помощью ИИ было навайбкодено приложение «Киноархив» — сервис для ведения личной фильмотеки, рецензий и списков фильмов

Инструмент в плане дизайна похож на фигму. Из нового: я поработала с базой данных, добавила 3 записи вручную через App Data. Освоила workflows — реализовала CRUD (создание, чтение, редактирование, удаление) для фильмов на отдельной странице. Разобралась с Global variables (создала переменную и применила её к кнопке), стилями и готовыми компонентами из библиотеки Bubble. 

Отдельным этапом была ачивка с плагином. Это оказалось самым сложным. Остановилась на Slideshow A — плагин для слайд-шоу и настроила его для показа карточек фильмов.

Считаю, что инструмент неплохой, но ему есть куда стремится. Куча всяких багов. Если будет время как нибудь хотелось бы углубиться.
